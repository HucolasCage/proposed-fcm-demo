# Proposed FCM · 交互演示

[打开交互演示](https://hucolascage.github.io/proposed-fcm-demo/)

在同一组二维样本上观察小批量预热、中心重置和全量精修。可以自动播放、单步查看或拖动进度条。切换至「看拟牛顿试探如何回退」可查看一次候选目标下降不足的实际运行。

两种情景使用同一组 203 个合成样本，K = 4，m = 2。每种情景中的标准 FCM 使用同一组初始中心。目标曲线按等价全数据扫描数对齐。

动画呈现方式参考 [e-means 官方演示](https://e-means.github.io/)。

下载 index.html 可离线打开演示。
