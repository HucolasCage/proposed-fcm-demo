# Proposed FCM · 交互演示

在同一组二维样本上并排观察所提方法和标准 FCM。点击「中心重置」查看一个中心如何移到右下的小簇，再点「看最终结果」比较两种方法。也可以播放、单步查看或拖动进度条。另一条轨迹展示拟牛顿试探下降不足时的回退。

[打开交互演示](https://hucolascage.github.io/proposed-fcm-demo/?view=small-cluster)

## 图中的数值

合成数据由四组大小不同的二维高斯样本组成，样本数分别为 150、65、58 和 20。使用 K = 4 和 m = 2。展示重置和回退的种子分别为 0 和 45。每种情景中的标准 FCM 使用相同初始中心。对比曲线按等价全数据扫描数对齐。预热各批合计一次扫描，候选筛选、评价和回退也计入扫描成本。

在同一合成数据上，使用另外 50 个种子（50–99）作配对验证。所提方法在 26 次运行中同时达到更低目标值和更少扫描，其余 24 次最终目标差在 0.01% 以内。标准 FCM 有 26 次未给小簇分配自己的中心，所提方法为 0 次。这里将中心归给其最近的生成组样本均值，再检查右下小簇是否有中心。

网页回放从求解器导出的中心与目标值。中心动画的插值用于衔接相邻状态，曲线上的点对应实际评价。合成数据用于解释算法过程。

动画呈现方式参考 [e-means 官方演示](https://e-means.github.io/)。
